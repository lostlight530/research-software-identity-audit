Life Science Ecosystem Lab v0.4.0 — Registry-Integrated Research Software Baseline Life Science Ecosystem Lab v0.4.0 establishes the first release baseline of three independently callable life-science research-software assets maintained within one evidence-governed repository Life Science Knowledge Workflow Life Science Evidence Tool Life Science Protein File Audit Each asset has a separate callable interface, validation path and evidence boundary GitHub Actions is the native execution environment for the Knowledge Workflow and is not presented as a fourth research-software asset Life Science Knowledge Workflow The Knowledge Workflow implements a deterministic, source-grounded repository lifecycle for approved public GitHub evidence It can be executed through the native GitHub Actions lifecycle, the ls-knowledge command-line interface and a portable CWL v1.2 representation Its verified lifecycle includes: approved-source collection immutable Git object and content identity checks deterministic aggregation source-linked knowledge extraction schema and provenance validation rebuildable JSONL graph projection bounded SQLite FTS5/BM25 search explicit unknown and coverage-gap reporting guarded persistence to the accepted data/ boundary The first verified live production snapshot was accepted in GitHub Actions Run 38995485443 and commit b2d1d31f715275823f7ea0440d0a14a552f35e2a This historical acceptance demonstrates one verified production execution and does not by itself establish continuous availability or external scientific certification The portable CWL interface now includes human-readable labels and descriptions for every public input, step and output These metadata additions do not change the CWL execution graph, file types, command lines, step connections or deterministic output paths Life Science Evidence Tool The independently callable ls-evidence tool provides bounded research-software and evidence verification functions, including: source collection and deterministic aggregation evidence and schema validation nonexecuting external-repository inspection documentation-manifest auditing local Markdown-link auditing knowledge and ecosystem readiness checks JSON, Markdown and SARIF reports proposal-only external research-case validation The Evidence Tool distinguishes verified findings, observed conditions, unknowns and unverified external claims It does not convert repository metadata, registry presence or automated checks into claims of scientific validity Life Science Protein File Audit The independently callable ls-bio tool performs offline and deterministic bioinformatics processing for: amino-acid composition and ambiguous-residue analysis in protein FASTA files observed first-model C-alpha residue inventory in PDB coordinate files source SHA-256 reporting bounded input and quality warnings deterministic JSON reports Portable CWL CommandLineTool wrappers are supplied for the supported FASTA and PDB operations The tool does not predict protein structures, validate molecular geometry, infer biological mechanisms or provide clinical interpretation Its
