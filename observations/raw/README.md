# Raw observations

This directory is reserved for prospective observation records captured under a declared operational schedule.

Rules:

- preserve retrieval timestamps;
- preserve failed and incomplete attempts;
- keep source evidence references;
- do not overwrite earlier observations when platform state changes;
- keep historical baseline distinct from prospective observations;
- do not manufacture prospective records before the first eligible post-registration release event.

No prospective observation data is added by the bootstrap commit.
