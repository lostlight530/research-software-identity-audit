## Zenodo

Zenodo integration and badges belong to the repository-release archival/citation surface.

A Zenodo badge or DOI must identify the concrete Zenodo record minted for this repository or one of its releases. It must not be conflated with the OSF registration DOI.

Until the concrete Zenodo record/DOI is present and verified in this repository, machine-readable metadata must not invent one.

## Identity rule

GitHub repository identity, OSF registration identity, OSF project identity, Zenodo deposit identity, ORCID attribution, and downstream discovery records are related but non-equivalent scholarly objects.
