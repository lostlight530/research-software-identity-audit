These are immutable point-in-time inventories. Their path counts, blob counts, commit counts and event classifications must be cited with their pinned source commit and retrieval/compilation time. They are not current `main` metrics, new platform observations, prospective timepoints, or evidence that every listed file's semantic contents were manually reviewed.

The directory move preserves the inventory package contents. Historical `source_path` fields continue to describe the source Git tree each inventory actually examined, including legacy `monitoring/` and `evidence/` paths. Do not rewrite those historical source-path fields to match the current archive layout.
