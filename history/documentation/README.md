# Historical documentation archive

This directory contains the 35 historical repository-control documents relocated from `docs/history/`, together with the original path-convention source document preserved from `monitoring/NAMING.md`.

## Source preservation and current authority

- The original `docs/history/README.md` is preserved byte-for-byte as [`README.source.md`](README.source.md). Its path statements and relative links describe its source-era tree and are not current navigation authority
- The original `monitoring/NAMING.md` is preserved byte-for-byte as [`record-path-conventions.source.md`](record-path-conventions.source.md). It is a historical policy snapshot, not the current path contract
- The current repository path and ownership policy is [`docs/record-path-conventions.md`](../../docs/record-path-conventions.md)
- The unified archive map is [`history/README.md`](../README.md)

## Categories

- [`inventory-ledgers/`](inventory-ledgers/) — Git path/blob inventories, commit and PR ledgers, governance and lifecycle snapshots
- [`method-and-integrity-reviews/`](method-and-integrity-reviews/) — dated semantic/path/integrity assurance notes and local preflights
- [`diagnostic-and-closeout-reviews/`](diagnostic-and-closeout-reviews/) — bounded platform snapshots, correction notes, and research-session closeouts

These files remain historical repository documentation. They do not become current contracts, new observations, or active monitoring instructions merely because their paths are now under `history/`.
