# Provenance

The project preserves the chain:

source evidence
→ raw observation
→ normalized/derived observation
→ analysis
→ interpretation
→ reported conclusion

Important provenance boundaries:

- historical state vs current live state;
- preregistered rule vs operational specification;
- planned analysis vs exploratory/post hoc analysis;
- original observation vs later correction;
- source object vs aggregated representation.

Every substantive correction should preserve the previous state rather than erase it.
